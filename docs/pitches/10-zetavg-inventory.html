Estudar · UX RFID em produção

A cara que um RFID app deveria ter no dia-a-dia

zetavg/Inventory é um app open-source pessoal de inventário RFID — mas o cara modelou os fluxos certos: tag órfã, batch action, heat-map de localização, persistência de "última vez que vi este serial". É exatamente o que precisamos olhar antes de polir o app iOS.

MIT React Native · TS RFID UX patterns github.com/zetavg/Inventory ↗
O que ainda falta no app iOS

O fluxo "lê 200 tags de uma vez" é mais complicado do que parece

  • O que fazer quando uma tag lida não está no banco? Hoje o app só ignora
  • Como dizer "este serial foi visto hoje" sem registrar movimento? Não existe
  • Batch action — selecionar 50 seriais escaneados e fazer ação única (ex: marcar todos como retornados) não existe limpo
  • Sinal de RSSI dá distância — não usamos pra dizer "tá perto" vs "tá longe" na busca de equipamento perdido
O que extrair

5 patterns de UX que valem replicar

  • Tag órfã com ação rápida: tag lida + não cadastrada → botão "Cadastrar agora" inline, sem sair da sessão
  • "Last seen": registra timestamp da última leitura RFID em todo serial — vira "perdi este equipamento, onde foi visto pela última vez?"
  • Heat-map de proximidade: usa RSSI pra dizer "frio/quente/fervendo" → encontra equipamento sumido no galpão
  • Saved locations: "área de check-out", "área de retorno", "manutenção" — funcionário escolhe o contexto antes de scanear
  • Batch action multi-select: inverso do nosso fluxo atual — escaneia primeiro, decide depois

Limitações

É projeto pessoal, não corporativo

  • Manutenção é de uma pessoa só — pode parar a qualquer momento
  • Stack React Native — não dá pra copiar código Swift; só padrões mentais
  • Reader específico (UART/Bluetooth genérico) — não cobre Zebra SDK
Veredito

Inspiração de UX, não fonte de código.

Abrir o app deles (tem screenshots no README), rodar uma demo, anotar o que faz sentido pro galpão do Marcelo. Custo: 1 tarde. Resultado: 4 issues novas pro app iOS que vão fazer diferença pra funcionário que carrega o leitor o dia inteiro.
