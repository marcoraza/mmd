# Delete legacy lotes

Lotes legados serão apagados fisicamente, em vez de permanecerem arquivados para histórico ou bloquearem a remoção até uma conferência de contagem. A decisão simplifica o modelo operacional futuro, onde toda peça física é uma unidade rastreável, aceitando o risco de perda de vínculo direto em leituras antigas e possível divergência se alguma unidade ainda não existir.
