Infra · Hardware · Quando comprar a térmica

Etiqueta sai direto do browser pra impressora

Hoje o /qrcodes gera PDF com folha A4 cheia de QR codes — Marcelo imprime e corta. Funcionará por 1 ano. Quando ele comprar uma Brother QL-820 (térmica de etiqueta adesiva), o fluxo certo é: clica no serial → etiqueta sai. Sem driver, sem PDF intermediário. qZ Tray + OpenLabelMaker entregam essa ponte.

LGPL · qZ Tray free Browser → ZPL/ESC-POS Brother · Zebra · DYMO qz.io ↗
O fluxo atual de etiquetagem

PDF → impressora comum → tesoura → fita adesiva

  • Marcelo gera folha A4 de 24 QR codes — bom pra lote inicial, ruim pra dia-a-dia
  • Equipamento novo chega → precisa imprimir folha inteira pra usar 1 etiqueta
  • Etiqueta colada com fita adesiva descola — etiqueta térmica autoadesiva resolve
  • Sem indicação visual de "este serial precisa de re-etiquetagem"
O que ganhamos quando a Brother QL chegar

Impressão "1 clique" pra etiqueta adesiva resistente

  • Painel do serial → botão "Imprimir etiqueta" → sai da Brother QL na hora
  • qZ Tray instala uma vez no Mac do Marcelo, browser conversa direto via WebSocket local
  • Driver-less: zero configuração além de ligar a impressora
  • Suporte a Brother QL, Zebra (ZPL), DYMO, ESC/POS — escolhe a impressora que comprar
  • OpenLabelMaker como referência de layout: QR + código + nome + categoria em etiqueta de 62×29mm
  • Em lote: seleciona N seriais no /items → imprime sequência inteira

O que não esquecer

  • qZ Tray é gratuito sem certificado digital, mas mostra aviso de "untrusted" — pra produção, paga ~$60/ano de certificado ou self-sign
  • Cada impressora tem linguagem própria (ZPL, ESC/POS, Brother RAW) — primeira integração é específica do modelo escolhido
  • iPhone não imprime via qZ Tray (é solução desktop) — fluxo mobile fica via Bluetooth direto, projeto separado
  • Comprar Brother QL é decisão do Marcelo — não acelerar sem ele querer
Veredito

Não fazer agora. Listar como "quando comprar impressora térmica".

Implementar antes do hardware chegar é desperdício. Mas vale ter no roadmap pronto: momento que Marcelo decidir comprar a Brother QL (provavelmente quando o cadastro inicial ficar completo), a integração vira sprint de 3 dias em vez de pesquisa do zero.
