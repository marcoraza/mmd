Resource Calendar · MIT · 2 dias de integração

O mês inteiro de eventos numa tela só

ilamy-calendar é o que o FullCalendar Scheduler queria ser: resource timeline, drag-and-drop, RFC 5545 — tudo MIT, sem licença paga. A view que falta no MMD pra Marcelo enxergar conflitos antes de prometer equipamento pro segundo cliente.

MIT React Resource Timeline github.com/kcsujeet/ilamy-calendar ↗
O problema hoje

A página /projetos tem list/kanban/calendar — mas sem resource view

  • Marcelo não vê, na mesma tela, quais equipamentos estão fora em cada data
  • Conflito de alocação só aparece no momento do check-out, não no planejamento
  • FullCalendar Scheduler (resource timeline) é pago — não dá pra usar em consultoria de R$3k/mês
  • Sem visão semanal/mensal de carga operacional — não dá pra prever buraco de equipe
O que ganhamos

Nova view "Calendário Operacional" em /projetos?view=resource

  • Eixo Y = equipamento crítico (mesa Behringer X32, microfone wireless principal, projetor)
  • Eixo X = dias do mês
  • Bloco colorido = projeto que reservou aquele equipamento naquele intervalo
  • Sobreposição visual = conflito → toast vermelho instantâneo
  • Drag-and-drop pra reagendar evento — o packing list segue junto
  • Eventos recorrentes (manutenção mensal, devolução padrão D+1) via RFC 5545
  • Pode virar feed iCal pro Google Calendar do Marcelo (export futuro)

O que considerar

  • Biblioteca é nova — comunidade menor que FullCalendar, possíveis bugs em edge cases
  • Não tem suporte nativo a internacionalização brasileira completa — pt-BR pode precisar config
  • Mobile: timeline horizontal em iPhone fica apertada — precisa de view alternativa por dia
Veredito

É a feature mais "premium" do deck sem custar dinheiro.

Resource timeline é o que separa um sistema de inventário caseiro de um "Rentman de verdade". O fato de ter uma alternativa MIT decente (raro) é uma janela rara — vale aproveitar antes que vire moda e fique caro.
