PDF · Romaneio · Recibo · 2 dias de integração

O cliente sai com um PDF assinado, não com uma planilha mental

Já temos @react-pdf/renderer rodando (gera as folhas de QR). Falta o documento de negócio: romaneio na saída, recibo na devolução, contrato com assinatura. react-invoice-generator dá o template e a UX de edição com preview ao vivo — copia, adapta, integra.

MIT React · @react-pdf Live preview github.com/tuanpham-dev/react-invoice-generator ↗
O problema hoje

Operação sem papel é operação sem prova

  • Cliente recebe equipamento — não há documento listando o que saiu, em que estado, com qual valor de cobertura
  • Equipamento volta — não há ata de devolução com fotos de dano ou checklist de retorno
  • Em caso de quebra, conversa vira "Marcelo disse" vs "cliente disse" no WhatsApp
  • Funcionário do galpão não tem checklist físico pra conferir saída
O que ganhamos

3 documentos automáticos a partir dos dados que já existem

  • Romaneio de saída: lista de seriais alocados ao projeto, com codigo interno, foto e desgaste atual — gerado no momento do check-out
  • Recibo de devolução: mesma lista com checklist de "OK / dano / faltante" — gerado no check-in
  • Contrato/orçamento: valor de mercado, condições, prazo — pra fechar com cliente
  • UX de edição lado-a-lado: Marcelo ajusta condições e vê o PDF mudando em tempo real
  • Logo MMD + assinatura visual Liquid Glass (cabeçalho com caustic) — branding consistente
  • Envio direto por email (futuro: integração com Gmail MCP)

O que considerar

  • O repo é mais "inspiração" do que "lib instalável" — vamos copiar componentes e adaptar
  • Assinatura digital de verdade (ICP-Brasil) é outro projeto — começamos só com PDF impresso/assinado físico
  • Templates precisam de revisão jurídica do contrato real do Marcelo antes de virar default
Veredito

É o que transforma o sistema em "produto operacional", não "sistema de cadastro".

Sem PDF de romaneio, o sistema é um Excel bonito. Com PDF, ele substitui o caderno do Marcelo. É o entregável que ele leva pra cliente e diz "olha o nível do meu sistema". O custo é baixo porque o stack já está lá.
